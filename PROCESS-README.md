# Kontor process archive

This branch holds HackFleet orchestration, agent research, tasks and review records, separated from the product branch. New process artifacts belong here, never in the application tree.

All accountant reviews in this archive were performed by **AI accountant-persona agents**, not human accountants. Fresh contexts and browser-only instructions were used where recorded; filesystem isolation was not enforced. These are simulated usability assessments, not professional accounting validation or a security audit. Historical labels and scores must be interpreted with this disclosure.

This branch initially snapshots the product at the point of separation. Main is the current product source. Moving records here does not remove earlier commits from Git history.
